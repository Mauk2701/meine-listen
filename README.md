# Meine Listen

Eine kleine Web-App für To-dos und eine getrennte Einkaufsliste.

- To-dos mit Erinnerung, Kategorie (Uni, Privat, Arbeit) und Stern für Wichtiges
- Einkaufsliste zum Abhaken
- Läuft im Browser und lässt sich auf dem iPhone zum Home-Bildschirm hinzufügen
- Alle Einträge bleiben nur auf dem eigenen Gerät gespeichert

Gebaut mit HTML, CSS und JavaScript, zusammen mit Claude.
